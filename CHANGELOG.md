# Changelog

## 1.0.0 — 2026-10-13

First public release.

- Database abstraction (`TrackName`, `TrackSource`, `VitalSignal`, `DatabaseType`) and a single
  acquisition entry point, `loadPatientCase`, returning a `Patient` and canonical `patientData`.
- VitalDB acquisition with local caching of the track index and of every downloaded track;
  cohort search from a signal specification (`searchPatients`).
- Volatile agents: sevoflurane and desflurane from the Dräger Primus (kPa → vol%) and the
  Solar8000 total gas, with automatic agent resolution.
- PK: Schnider (propofol), Minto (remifentanil), Joachim (norepinephrine), first-order volatile
  effect sites with Mapleson age adjustment.
- PD: additive Minto, Bouillon and reduced Greco BIS models in parallel; reduced Greco with
  volatile agents; turnover MAP/HR model; unified propofol–remifentanil–norepinephrine MAP model.
- Simulink model generated by `build_anesthesim_model`; PD equations shared between the
  Simulink blocks and offline analyses.
- Validation on real records: the VitalDB cohort is replayed through the simulator
  (`study_validation`, `analyze_validation`) with Varvel performance metrics and BIS
  signal-quality (SQI) filtering; blind check of the volatile-agent resolution.
- Alarm detection with configurable limits.
- Examples reproducing the figures of the accompanying paper; unit tests and CI.
